# Code Refactor Agent

`Code Refactor Agent` is a runnable multi-language refactoring CLI that scans a repository, builds an execution plan, applies safe automated fixes, and emits review-ready pull request artifacts.

It is designed as a practical GitHub project rather than a slide-only concept:

- `Analyzer`: discovers files, detects rule-based refactor opportunities, and gathers agent insights
- `Planner`: ranks work items and assigns them to simulated specialist agents
- `Executor`: applies safe automated rewrites and generates unified diffs
- `Verifier`: recompiles Python files and runs lightweight checks for other languages
- `ArtifactWriter`: emits a patch file and a pull-request style markdown report

## What Was Upgraded

This version now includes all three upgrades:

1. Optional `OpenAI` or `Claude / Anthropic` planning provider integration
2. A multi-agent orchestration layer with `architect`, `planner`, `writer`, and `reviewer` style roles
3. Multi-language scanning support for `Python`, `TypeScript`, `JavaScript`, `Java`, and `Go`

## Features

- Works fully offline with a local fallback provider
- Supports optional LLM-backed planning notes
- Produces terminal, JSON, unified diff, and PR markdown outputs
- Applies safe automated refactors across supported languages
- Keeps changes reviewable and grouped by file

## Supported Refactors

- Python `None` comparison normalization
- Redundant boolean comparison cleanup for Python, TypeScript, JavaScript, Java, and Go
- Trailing whitespace cleanup
- Single newline at end of file

## Quick Start

Run directly from the repository:

```bash
python main.py scan ./examples
python main.py apply ./examples --write --emit-diff --emit-pr-report --artifacts-dir ./artifacts
```

## Multi-Agent Planning

Local planning works out of the box:

```bash
python main.py scan ./examples --provider local --report json
```

To enable provider-backed planning:

```bash
python main.py scan ./examples --provider openai --model gpt-4.1-mini --enable-llm-planning
python main.py scan ./examples --provider claude --model claude-3-5-sonnet-latest --enable-llm-planning
```

Environment variables:

- `OPENAI_API_KEY`
- `ANTHROPIC_API_KEY`

## Pull Request Artifacts

Apply changes and emit artifacts:

```bash
python main.py apply ./examples --write --emit-diff --emit-pr-report --artifacts-dir ./artifacts
```

Generated files:

- `artifacts/refactor.patch`
- `artifacts/pull_request.md`

## GitHub Actions

The repository includes a CI workflow at `.github/workflows/ci.yml`.

It runs on every push and pull request, across `Python 3.10`, `3.11`, and `3.12`, on both `Ubuntu` and `Windows`.

CI validates:

- editable install works
- unit tests pass
- `scan` command runs successfully
- `apply` command can generate refactor artifacts

## Architecture

The project uses a hybrid approach:

- Safe deterministic rewrites are handled by local rules
- Planning and rationale can optionally be generated by OpenAI or Anthropic
- Multi-agent coordination adds architecture review, risk review, and execution rationale to each file plan

This keeps the tool runnable offline while making it straightforward to evolve into a stronger AI-native refactoring workflow later.
